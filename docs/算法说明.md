# 方案一(单帧基线管线)算法说明

> 本工程实现 `总体方案.md` 中的共用预处理(§1.2)、方案一管线(§2)、
> 特征提取与分类规则(§4)、参数表(§5)与验证回调(§7)对应的软件部分。

## 管线流程

```
读取 R-JPEG → 温度矩阵 T(℃)
      │
      ▼
预处理:① 发射率校正(ε=0.90,SB 近似)→ ② 3×3 中值去噪 → ③ GSD
      │
      ▼
方案一:① 去趋势 T_anom = T − 高斯模糊(T, σ),σ = 2~3×缺陷半径
       ② 噪声估计 σ_noise = MAD(T_anom)×1.4826
       ③ 标准化 z = T_anom / σ_noise
       ④ 阈值 |z|>2.5 → 热斑(warm)/ 冷斑(cold)
       ⑤ 连通域提取,剔除面积 <25px 的斑块
      │
      ▼
特征提取(§4):ΔT、边界锐度、内部均匀度、矩形度、伸长率(+长轴竖直度)
      │
      ▼
规则分类(§4):窗户(非缺陷)/ 空鼓 / 渗水 / 其余(人工复核)
      │
      ▼
输出:temperature.npy、overlay.png、mask_*.png、defects.csv、summary.json
      │
      ▼
现场验证(§7)→ 回调 config/defaults.yaml 参数 → 重新运行
```

## 关键设计说明

1. **发射率校正**:统一 ε=0.90,采用斯特藩-玻尔兹曼近似的辐射校正
   `W(T_surf) = (W(T_meas) − (1−ε)·W(T_refl)) / ε`。严格做法见
   `延伸篇.md` §10.4(8–14µm 波段积分、SDK 标定、材质 ε 图)。
2. **定性条件默认关闭**:§4 表格中的"边界锐利""边界弥散""长轴偏垂直"
   为定性描述,伪代码未使用;工程实现为可选开关(与全图平均边缘锐度比较、
   与竖直方向夹角容差比较),默认关闭以与伪代码一致。
3. **长轴竖直度**:由斑块像素坐标的 PCA 主方向计算,不依赖
   `cv2.minAreaRect` 的角度约定,结果 0~1(1=竖直)。伸长率取
   minAreaRect 返回两边的 max/min(其 (w, h) 顺序不保证)。
4. **分类为规则分类(非机器学习)**:特征人工设计、阈值人工设定、现场验证后
   人工回调。机器学习方案见 `延伸篇.md` §9(方案三)。
   本项目在 总体方案.md §4 四条规则之外**新增"形状渗漏"一条**:冷斑块矩形度高
   (`seepage_rect` = 0.80)且细长(`seepage_rect_elong` = 2.0)即判渗漏,**不看 ΔT**——
   规则的矩形形状比温差更能说明问题。可选的 `seepage_shape_require_cold`(默认 `false`)
   开启后叠加 `seepage_shape_dt_c`(默认 −0.8)下限,用来挡掉浅温差的弱信号。
   优先级:**窗户之后、空鼓/渗水 ΔT 规则之前**。"长轴偏垂直"开关对两条渗水规则都生效。
5. **照片边界当作墙(`detect.border_ignore_px`,默认 15px)**:最外一圈不参与
   检测,避免窗外未拍全、边界外无墙可比造成的边界伪影(实测 test01 有 12 个
   斑块挤在左边缘 `x=0`)。只在检测掩膜上扣,不改像素值——垫边填充会在四边
   墙面温度不一致时造出阶跃(实测四边中位数相差 4.12℃,垫边后斑块数
   40→101→191),并会改变 MAD 噪声估计。
   **边界带是"检测口径",不是"形状口径"**:斑块在带内有足够像素即被检出,
   但形状取自它所属的**完整**连通域。因为带会把斑块轮廓沿直线切直、把
   `rect`/`elong` 人为拉高(实测 rect 0.66→1.00、elong 1.91→6.00);回查完整
   连通域后,跑出画面的细长渗漏能按真实形状判出来(实测同一条渗漏:切过时
   elong=13.85、完整时 14.31,而边界切出的伪影完整时只有 rect=0.67
   elong=1.91,自然被形状规则挡住)。同一完整连通域被带切成两段时只报一次。
6. **窗区块长宽比(`window_mask.aspect_min/aspect_max`,0.15/6.67)**:限制
   "窗户区域块"能有多细长。原值 0.08/12.5 以为"渗水是实心细条 rect≈1"、
   靠 rect 就能挡住,但实测有 rect 仅 0.44、宽高比 0.131(长/宽 7.6)的
   贯穿全画幅冷条被当成窗区块吃掉了;真正的窗区块宽高比在 2~3 附近。
7. **窗户掩膜(两遍式)**:窗户反光会造成窗内红外不均匀,产生大量虚假候选。
   识别为窗户后,整个窗户区域不作为识别条件:
   - 第一遍从 z 冷侧(z < −window_mask.z_threshold,比检测层宽松)找窗户——
     小闭运算(close_direct)抓单窗矩形(直接路径:最小外接矩形度 >0.85 且
     宽高比 ∈ [0.4,3.5]);大闭运算(close_kernel)合并成排/成列的窗户区域块
     (块路径:矩形度 ≤0.85、宽高比 ∈ [0.15,6.67] 且明显细长——近方形冷块
     多为去趋势伪影,不按窗户;比 0.15 更细长的按渗漏交给检测层判,见下条);
   - 掩膜按外接矩形填充(窗内反光暖区在冷掩膜里是孔洞,按斑块并集盖不住),
     再自适应生长覆盖过渡带:先膨胀 dilate_px 盖窗框,然后逐像素外扩,直到
     新增环带温度回到局部背景水平(环带中位数 ≥ 更外参考带 − grow_tol_c
     即停,grow_max_px 兜底)——去噪/窗框导热造成的过渡带随矩形一并删除;
   - 用 cv2.inpaint(NS)把窗户+过渡带谐波延续背景填平(不用 Telea:它在
     过渡带斜坡边界上产生 ±1℃ 棋盘纹;不用常数填充:边缘会造新的人工边缘);
   - 第二遍检测在净墙上进行;与掩膜覆盖率超过 exclude_overlap 的候选斑块
     直接排除(过渡带角部残留的零点几度冷缝),控制台打印排除计数;
     窗户本身仍以 label="window" 报出。
   参数集中在 defaults.yaml 的 `window_mask` 段,`enabled: false` 可关闭。
8. **叠加图显示过滤(`display` 段,本项目新增)**:按类别控制 `overlay.png` 画哪些
   斑块——每类一个 0/1 开关 + 一个长度下限(`min_len_*_px`,边框 `max(宽,高)`)。
   **只影响 `overlay.png`**:`defects.csv`、`summary.json`(含 `counts`)、
   `mask_NNN_*.png` 一律为全量,供复盘与追溯。
   **编号契约**:overlay 上的编号沿用斑块在缺陷列表中的下标,与 `defects.csv` 的
   `index` 列、`mask_NNN_*.png` 的 NNN 一一对应;被过滤的斑块只跳过绘制、**不重新
   编号**,故图上编号可能不连续——这是刻意的,便于对着 CSV 核对。
9. **绝对矩形掩膜(`rect_mask` 段,本项目新增,调试用)**:把温度图按
   `|T − median(T)| > dt_c` **转码**成二维二值矩阵,再对其中**规则粗边矩形**
   (轮廓四边逼近恰 4 顶点 + 凸 + 四角近 90° = "规则";最粗处 ≥ `min_edge_px` =
   "粗边")做**掩埋**:四边形填充成掩膜 → 膨胀 → NS 修复填平 → 沿用原方案继续
   去噪等处理。判据是**绝对**的(阈值是℃,不依赖噪声统计,也不做局部背景扣除),
   与窗户掩膜的统计口径(z 分数 + 形态学)互为对照。
   **粗边**这一条是后加的:光有"恰 4 顶点",一条 1px 粗的细线框也会被当成规则矩形。
   粗边量的是 2 × 最大内切圆半径——粗边框量到带宽、实心块量到短边,**实心与粗边框
   都算**(判据是"边够粗",不是"必须是环形")。量之前必须给二值矩阵**补一圈 0**:
   `cv2.distanceTransform` 不把画面外当背景,贴边的块会被量成整个宽度(实测 89px 宽
   量出 174px)。实测 1px 细线 = 2.0px、真实窗框/实心块 = 14~92px,故默认 3.0 只挡
   细线——**该门槛在现有数据上从未生效过**,是护栏不是主力判据。
   `dt_c` 是主要旋钮,取值影响很大(实测参考见总体方案.md §2.6)。
   启用时额外写 `rect_mask.png` 与 `summary.json` 的 `rect_mask` 段(含 `edge_px`)。
