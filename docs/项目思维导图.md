## 一、项目定位

## 二、物理原理与业务背景
- 空鼓的热特征
  - 空气层把饰面层与基层热隔离 → 失去基层这个热汇 → 热惯量小,响应更快、幅度更大
  - 升温时段(白天)→ 热斑(warm);降温时段(夜间)→ 反而偏冷(冷斑),符号随时相翻转
  - 故现场以"晴天下午抓空鼓"为主(降温段温差小、时间窗窄、要求低风速)
- 渗水的热特征
  - 水分蒸发吸热 → 表面偏冷(蒸发项始终偏冷;湿墙热惯量也增大,白天同向偏冷)
  - 夜间热惯量项反向,故以雨后蒸发旺盛时段为准
  - 沿墙流动 → 细长条带
  - 单帧表现:冷斑(cold)
- 窗户(非缺陷干扰)
  - 几何规则:矩形度高
  - 热特征:明显偏冷
  - 反光使窗内温度不均 → 大量虚假候选
- 传统检测痛点:人工敲击听响、吊篮高空作业、效率低
- 无人机优势:一次飞行覆盖整栋楼、逐像素温度数据

## 五、共用预处理
- io.py 数据读取
  - .npy:直接读温度矩阵
  - .jpg/.jpeg(R-JPEG):优先 DJI Thermal SDK 解析真实温度(开尔文 → ℃)
  - SDK 未安装/解析失败 → 回退灰度读取(仅开发调试,打印告警)
- preprocess.py
  - 发射率校正:W(T_surf) = (W(T_meas) − (1−ε)·W(T_refl)) / ε
    - 斯特藩-玻尔兹曼近似 W = σT⁴(工程简化)
    - ε = 0.90 统一初值;严格做法见 延伸篇.md §10.4
  - 去噪:3×3 中值滤波(去椒盐噪声)
  - GSD:distance_m / 540(Mavic 3T 经验系数)→ 像素面积换算物理面积 m²

## 六、方案一:单帧基线管线
- 窗户掩膜(识别为窗户后,整块矩形不作为识别条件)
  - 第一遍:z 冷侧宽松阈值 + 闭运算找窗户(单窗矩形 / 成排成列区域块)
  - 掩膜按外接矩形填充(窗内反光暖区是孔洞,并集盖不住)
  - 自适应生长覆盖过渡带:先膨胀 dilate_px,再逐像素外扩,环带温度回到
    局部背景水平(参考带 − grow_tol_c)即停,grow_max_px 兜底
  - NS 修复(谐波延续)填平背景:不用 Telea(斜坡边界 ±1℃ 棋盘纹)、
    不用常数填充(人工边缘被下一段检测误判)
  - 第二遍:与掩膜覆盖率 > exclude_overlap 的候选直接排除并打印计数
- 五步检测(detect.py,§2)
  - ① 去趋势:T_anom = T − 高斯模糊(T, σ=20px);σ ≈ 2~3×缺陷半径
  - ② MAD 噪声估计:σ_noise = MAD(T_anom) × 1.4826
  - ③ 标准化:z = T_anom / σ_noise(零方差保护)
  - ④ 双侧阈值:|z| > 1.5 → 热斑(warm)/ 冷斑(cold)
  - ⑤ 连通域提取:剔除面积 < 50px 的斑块
  - ⑥ 边界带:照片最外 15px 当作墙,不参与检测(见下)
- 关键思想
  - 去趋势:消除整墙日照/朝向梯度背景
  - MAD 而非标准差:异常斑块本身是离群点,标准差会被拉大,MAD 稳健
- 边界带(detect.border_ignore_px,本项目新增)
  - 只作用于**检测掩膜**,不改像素值;0=不过滤
  - 不用"外扩填墙面温度":四边墙面温度本就不一致(实测差 4.12℃),填常数会造阶跃,
    反而把伪影炸开(斑块数 40→101→191),还会改变 MAD 噪声估计
  - **是"检测口径"而非"形状口径"**:带会把轮廓切直、人为拉高 rect/elong
    (实测 rect 0.66→1.00、elong 1.91→6.00),故形状回查**完整**连通域,
    同一连通域被切成两段只报一次
- 核心参数
  - detrend_sigma_px = 20 / z_threshold = 1.5 / min_area_px = 50 / border_ignore_px = 15
  - 窗户掩膜:dilate_px / grow_tol_c / grow_max_px / exclude_overlap / inpaint_radius
    / aspect_min = 0.15 / aspect_max = 6.67(窗区块不能比这更细长)
- 绝对矩形掩膜(rect_mask 段,**调试用**,§2.6)
  - 转码:|T − median(T)| > dt_c → 二维二值矩阵(绝对温差,双侧,不依赖噪声统计)
  - 规则 = 轮廓四边逼近恰 4 顶点 + 凸 + 四角近 90°
  - 粗边 = 最粗处(2 × 最大内切圆半径)≥ min_edge_px
    - 粗边框量到带宽、实心块量到短边;实心与粗边框**都算**
    - 光有"恰 4 顶点"时 1px 细线框也会被当成规则矩形,这一条专挡它
    - 量前必须给二值矩阵补一圈 0:distanceTransform 不把画面外当背景
    - 实测 1px 细线 = 2.0px、真实窗框/实心块 = 14~92px → **该门槛在现有数据上从未生效**
  - 掩埋 = 四边形填充 → 膨胀 → NS 修复填平 → 沿用原方案继续去噪等处理
  - dt_c 是主要旋钮,取值影响很大;approx_eps 决定能否凑出"恰 4 顶点"
  - 清单条数 ≠ 目标个数(目标内部有反差结构时会裂成多个四边)
  - 启用时额外产出 rect_mask.png 与 summary.json 的 rect_mask 段(含 edge_px)
- 后续:特征提取 → 规则分类 → 输出 → 现场验证 → 回调重跑

## 七、特征与分类(§4)
- 5+1 个特征(features.py)
  - dT:斑块均值 − 外围膨胀环带均值(局部温差 ℃)
  - sharp:斑块内 |拉普拉斯| 均值(边界锐度,全图均值 sharp_ref 作参考)
  - uniform:斑块内温度标准差(内部均匀度)
  - rect:面积 / 最小外接矩形面积(矩形度)
  - elong:长轴/短轴(伸长率;minAreaRect 两边 max/min,(w,h) 顺序无保证)
  - verticality:长轴竖直度 0~1(由像素坐标 PCA 主方向算,不依赖 minAreaRect 角度约定)
- 规则分类(classify.py,按序判定、命中即返回)
  - 窗户(非缺陷):rect > 0.85 且 dT < −5℃(+可选:边界锐利)
  - **形状渗漏(本项目新增)**:rect > 0.80 且 elong > 2.0 —— **不看 ΔT**
    - 可选 seepage_shape_require_cold(默认 false)开启后叠加 dT < −0.8
  - 空鼓(warm 斑块):dT > 1.5℃ 且 rect < 0.8(+可选:边界弥散)
  - 渗水(cold 斑块):dT < −1.5℃ 且 elong > 1.5(+可选:长轴偏垂直,容差 20°)
  - 其余 → reject(交人工复核)
- 定性条件(锐利/弥散/偏垂直)默认关闭,与伪代码一致;开启后与 sharp_ref 比较
- 注:elong 与 seepage_rect_elong 是同一个量(都是 minAreaRect 长轴/短轴),分属两条规则;
  "长轴偏垂直"开关对**两条**渗水规则都生效,否则会被形状规则静默绕过

## 八、编排与输出(pipeline.py)
- run_single(T):方案一完整管线(预处理 → 窗户掩膜删除 → 检测 → 特征 → 分类)
- 输出文件(每个输入在 data/output/<名称>/ 下)
  - temperature.npy:校正后的温度矩阵(℃,float32;已删除窗户区域)
  - overlay.png:温度伪彩(INVERNO)+ 缺陷轮廓 + 标签(人工复核用)
  - mask_NNN_类别.png:每个斑块的二值掩膜
  - defects.csv:缺陷清单(坐标/面积/ΔT/5 特征/来源 source 恒为 single)
  - summary.json:汇总 + 完整参数快照(可复现)
- display 段(本项目新增,只影响渲染)
  - 每类一个 0/1 开关 show_* + 一个长度下限 min_len_*_px(边框 max(宽,高))
  - **只影响 overlay.png**;CSV / summary(含 counts)/ mask 文件一律全量
  - 编号契约:overlay 编号 = 缺陷列表下标 = CSV 的 index 列 = mask 的 NNN,
    被过滤的只跳过绘制不重新编号,故图上编号可能不连续(刻意,便于对照 CSV)
