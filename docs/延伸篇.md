## 9. 方案三:深度学习增强

### 9.1 定位与分工

- 规则管线(方案一/二)的优点是可解释、参数少、可现场回调;瓶颈在"窗户与缺陷混淆、弱对比场景"。
- 方案三(DL)专门补这两块短板,与规则管线是**并行通道**而非替代关系。
- 原则:规则管线永远保留作为兜底,DL 不可用(算力/模型缺失)时仍能独立出结果。

### 9.2 模型选型

| 通道 | 任务 | 推荐模型 | 标注成本 | 适用 |
|---|---|---|---|---|
| A | 无监督异常检测 | PatchCore / PaDiM | 仅需正常墙面图像 | 新楼冷启动,零缺陷标注 |
| B | 像素级语义分割 | U-Net / DeepLabV3+ / SegFormer | 像素标注 | 有积累标注后的主力 |
| C | 可见光窗户检测(辅助) | YOLOv8 等 | 框标注 | 窗户掩膜,补充/替代三维凹陷法 |

### 9.3 输入设计(关键)

单通道热图不是最优输入,拼接先验通道:

| 通道 | 来源 | 作用 |
|---|---|---|
| T | R-JPEG 读出 | 原始温度 |
| z | 方案一 z 分数 | 已去趋势/标准化,降低学习难度 |
| PC2/PC3 | 方案二分量(有时相时) | 时间动态信息 |
| 可见光灰度 | 配准后 | 纹理与窗户位置先验 |

### 9.4 融合判定

| 模式 | 做法 | 适用 |
|---|---|---|
| 投票 | 规则 + 通道A + 通道B,≥2 票判缺陷 | 精度优先 |
| 级联 | 规则初筛 → DL 仅复核候选区 | 大范围作业,算力优先 |
| 冲突 | 任一通道高置信异常且与其他通道冲突 → 人工复核 | 兜底 |

### 9.5 标注与主动学习

- 起步:第 7 节现场验证时顺手框选,弱标注即可训练通道 C,再滚雪球扩充 B。
- 主动学习:对推理结果按熵排序,挑 top-K 不确定块送人工标注:

```python
# 主动学习:按像素熵挑最不确定的块
prob = model(inp)                                   # (1,C,H,W)
ent  = -(prob * np.log(prob + 1e-9)).sum(axis=1)    # 每像素熵
# 按 64×64 分块求平均熵,取 top-K 送人工标注
```

- 迭代节奏:每轮现场验证后全量重训(数据量小)或微调(数据量大)。

### 9.6 推理伪代码

```python
import torch

# 通道B:语义分割推理
model = load_model('seg_thermal_v3.pt')
inp = np.stack([T, z, gray], axis=0)[None].astype('float32')  # (1,3,H,W)
prob = model(torch.from_numpy(inp))[0].numpy()       # (4,H,W): 背景/窗户/空鼓/渗水
cls  = prob.argmax(0)
conf = prob.max(0)

# 融合:规则 + DL 投票(逐像素)
rule_map = rule_result(T)          # 来自第4节分类规则
vote = (rule_map == cls) + (conf > 0.8)
final = cls * (vote >= 1)          # 阈值按通道数调整(三通道时取 ≥2)
```

## 10. 定量评估:从检测到测量

### 10.1 像素 → 物理面积

```
① 平面假设(小立面、近似正对):
   面积 = 像素数 × GSD²,GSD ≈ D/540 m/px
② 倾斜校正(光轴与立面法线夹角 θ):
   面积 = 像素数 × (GSD / cosθ)²
   θ 由航线角 + 云台角得出,或由单应矩阵分解得出
③ 曲面/大立面:
   用摄影测量 DSM 重投影,按三角面片累加真实面积
```

```python
def area_m2(blob, gsd, theta_deg=0):
    k = 1.0 / np.cos(np.deg2rad(theta_deg))
    return blob.sum() * (gsd * k) ** 2
```

### 10.2 严重度分级(初值,按规范与现场复核回调)

| 等级 | 空鼓 | 渗水 |
|---|---|---|
| 轻微 | 面积<0.05 m² 且 1.5<ΔT<3℃ | 面积<0.1 m² 且 −3<ΔT<−1.5℃ |
| 中等 | 0.05~0.3 m² 或 3≤ΔT<5℃ | 0.1~0.5 m² 或 ΔT≤−3℃ 且单时段稳定 |
| 严重 | >0.3 m² 或 ΔT≥5℃ | >0.5 m² 或多时相持续存在 |

> 阈值为初值,需按当地检测规程(如 JGJ/T 277 红外热像法检测外墙饰面粘结质量等)与现场复核结果回调。

### 10.3 三维集成

```
可见光影像(高重叠) → 摄影测量重建(COLMAP / OpenMVG+MVS / 商业软件)
        │
        ├─→ 立面网格/DSM
        ├─→ 各时相温度图重投影为网格纹理 → 三维温度模型
        └─→ 按立面展开为正射温度图(便于归档、面积量算、报告插图)
```

- 用途:缺陷定位到"楼栋-立面-展开坐标"、曲面面积计算、多时相变化的直观展示。

### 10.4 材质发射率细分(预处理延伸,衔接 1.2②)

- 流程:可见光语义分割 → 材质图 → ε 图 → 逐像素辐射校正
- 校正(简化):T_surf = B⁻¹( (B(T_meas) − (1−ε)·B(T_refl)) / ε )

```python
# 斯特藩-玻尔兹曼近似(严格应使用 8–14µm 波段积分与 SDK 标定曲线)
SIGMA = 5.67e-8
def rad(t):       return SIGMA * (t + 273.15) ** 4
def inv_rad(W):   return (W / SIGMA) ** 0.25 - 273.15

def correct_emissivity(T_meas, eps_map, T_refl=20):
    W = (rad(T_meas) - (1 - eps_map) * rad(T_refl)) / eps_map
    return inv_rad(np.clip(W, 0, None))
```

- T_refl 取环境大气温度;严格做法在场景中放置已知 ε 的参考板标定。

| 材质 | ε 初值 | 备注 |
|---|---|---|
| 砖 | 0.90 | 与原方案一致 |
| 混凝土 | 0.92 | 与原方案一致 |
| 涂料/饰面砂浆 | 0.93 | 需现场标定 |
| 玻璃 | 0.85 | 低辐射镀膜玻璃可低至 0.1 以下 |
| 铝板/金属 | 0.1~0.3 | 强烈依赖氧化与涂层,温度不可靠 |

- 低 ε 区(玻璃/金属):温度不可靠 → 标记"不可测"并从缺陷判定中剔除,窗户由可见光通道兜底。

## 11. 工程化落地:批量作业与报告

### 11.1 大范围作业组织

- 分区:按楼栋/立面分块,航点飞行;同一建筑多时段**复用同一航点文件**。
- 重叠率:可见光按摄影测量要求(航向 80%、旁向 60% 起);热红外 ≥60%,满足配准与拼接。
- 批处理:目录规范 `楼栋/日期/时相/原始`,日志记录软件版本 + 参数快照 + 模型版本(保证可复现)。

### 11.2 自动报告

| 内容 | 说明 |
|---|---|
| 缺陷清单 | 编号/类别/位置(立面展开坐标)/面积/ΔT/等级/证据图 |
| 叠加图 | 温度伪彩 + 缺陷轮廓叠加到可见光正射图 |
| 统计 | 检出率、复核通过率、各类数量分布 |
| 验收附件 | 原始 R-JPEG 清单、飞行记录、处理参数快照 |

### 11.3 数据管理

- 原始 R-JPEG 永久留存:它是最终仲裁依据,任何重处理都从它开始。
- 处理产物带版本:参数快照 + 模型版本号,阈值回调后能追溯到每一版结果。

## 12. 数据闭环与模型迭代

```
现场验证(锤击/湿度计/目视)
        │
        ├─→ 规则侧:回调 z、ΔT、矩形度、σ、保留分量(衔接第7节)
        ├─→ DL 侧:验证结果转标注 → 全量重训/微调(9.5)
        └─→ 指标看板:检出率/误报率/混淆矩阵(窗户↔空鼓↔渗水)
```

- 每完成一个项目,积累:缺陷样本库、窗户样本库、各材质 ε 标定值。
- 目标:新项目冷启动时,规则阈值与 DL 模型已接近可用,现场工作量递减。

## 13. 风险与边界情况

| 风险 | 表现 | 对策 |
|---|---|---|
| 玻璃/金属反射 | 天空冷像、太阳热像形成假缺陷 | ε 图剔除(10.4);时段避开镜面反射角 |
| 阴影/太阳周期 | 阴影边缘梯度大,误触发 z 阈值 | 方案二时间载荷区分;正午前后拍摄 |
| 低纹理立面 | 图像配准失败,方案二不可用 | 航点位姿固定替代图像配准;退回方案一 |
| R-JPEG 位深/压缩噪声 | 微弱缺陷被量化噪声淹没 | 多帧平均;使用 SDK 最高精度输出 |
| 湿墙蒸发吸热 | 雨后假冷斑 | 雨后间隔拍摄;结合湿度计验证 |
| 冬季/阴天 | 对比度不足 | 晴天作业;不满足条件时出具"不满足检测条件"结论,不硬报 |
| DL 误判未见类别 | 新材质/新缺陷型漏检或误检 | 置信度阈值 + 人工复核;通道A(无监督)兜底 |
